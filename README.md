# Docs Management

Painel de gestão de documentos digitais com assistente de IA integrado, construído com **Next.js**, **React** e **TypeScript**, utilizando exclusivamente **dados fictícios**.

## Objetivo

Projeto de estudo e portfólio que demonstra desenvolvimento frontend sênior assistido por IA com validação técnica: especificações (SDD), decisões arquiteturais registradas (ADRs), testes automatizados, acessibilidade, segurança e entrega contínua.

## Status

🚧 Em desenvolvimento — fase 1: base de desenvolvimento assistido por IA (documentação, especificações e instruções para agentes).

## Fluxo de branches

| Branch     | Finalidade                                                                          |
| ---------- | ----------------------------------------------------------------------------------- |
| `main`     | Código estável, pronto para produção                                                |
| `develop`  | Integração das funcionalidades concluídas                                           |
| `<tipo>/*` | Trabalho do dia a dia, criado a partir de `develop` (ex.: `feat/`, `fix/`, `docs/`) |

Commits seguem o padrão [Conventional Commits](https://www.conventionalcommits.org/pt-br/v1.0.0/).
